# Project Context: System Hub (Next.js Application)

## 1. Tech Stack & Environment
- **Framework:** Next.js v16.2.12 (menggunakan **App Router**)[cite: 1]
- **Bahasa Pemrograman:** TypeScript[cite: 1]
- **Styling:** Tailwind CSS v4 (melalui PostCSS)[cite: 1]
- **State Management:** React Hooks bawaan (`useState`, `useEffect`, `useRef`)[cite: 1]
- **Database, Authentication & Storage:** Supabase (menggunakan `@supabase/ssr` dan `@supabase/supabase-js`)[cite: 1]
- **Library Tambahan:** 
  - `xlsx` untuk import/eksport data Excel[cite: 1]
  - `html2pdf.js` untuk konversi/generate dokumen ke PDF[cite: 1]
  - `react-signature-canvas` (atau ekuivalen) untuk digital signature pad

## 2. Project Structure
- `/app` - Direktori utama untuk routing aplikasi (App Router).[cite: 1]
  - `/app/dashboard/` - Halaman admin terproteksi. Berisi manajemen data utama (CRUD), filter, grid/list view, fitur import/eksport, serta bulk actions untuk alat-alat K3.[cite: 1]
  - `/app/dashboard/inspections/` - **(BARU)** Direktori/Rute khusus dan terisolasi untuk fitur Form Inspeksi dan Report, dipisahkan dari masterlist agar tidak mengganggu sistem yang sudah ada.
  - `/app/guest/` - Halaman guest/tamu (view-only mode) untuk melihat daftar dan status equipment tanpa harus login sebagai admin.[cite: 1]
- `/public` - Menyimpan file aset statis.[cite: 1]
  - `/public/form_checklist/` - Folder penting berisi berbagai *HTML template* form checklist bawaan yang nanti digunakan sebagai template untuk mencetak form. **(Tidak boleh diubah oleh fitur inspeksi baru)**.[cite: 1]
- **Root Configuration:** Konfigurasi standard seperti `next.config.ts`, `tsconfig.json`, `eslint.config.mjs`, `postcss.config.mjs`, dan file `.env`.[cite: 1]

## 3. Coding Conventions
- **Server/Client Components:** Komponen interaktif (form inspeksi kamera, signature pad, dashboard) wajib menggunakan `'use client'`.[cite: 1]
- **Data Fetching, Auth & Storage:** Interaksi dengan Supabase di sisi client dihandle melalui `createBrowserClient` dari `@supabase/ssr`.[cite: 1]
- **Styling & Structure:** Penggunaan murni Tailwind CSS utility classes di dalam atribut `className`. Mulai menggunakan arsitektur modular yang dipisah berdasarkan folder (misal `app/components/inspections/`).[cite: 1]

## 4. Current Status & Business Logic
- **Authentication Flow:** User yang mengakses halaman `/dashboard` akan di-cek sesinya. Jika tidak ada sesi aktif, otomatis redirect ke `/`.[cite: 1]
- **Admin Dashboard (Masterlist):** Manajemen masterlist alat K3 dengan CRUD, Paginasi, Filter, Unggah foto (Pic 1 dan Pic 2), dan Bulk Selection.[cite: 1]
- **Equipment Inspection & Finding Issues (ISOLATED MODULE):**
  - Modul baru yang hidup di halamannya sendiri (`/dashboard/inspections/[id]`). Tidak mengganggu form HTML lama.
  - Inspeksi checklist dengan jawaban Yes (Compliant) / No (Finding Issue).
  - Jawaban "No" memicu kewajiban input deskripsi masalah dan tenggat waktu (*scheduled date*) perbaikan.
  - **Live Photo Proof:** User diwajibkan mengunggah foto aktual dari lokasi menggunakan `<input capture="environment">` yang memblokir akses galeri dan memaksa kamera menyala.
  - **Digital Signature:** Validasi pelaporan menggunakan fitur tanda tangan digital pada kanvas interaktif.
  - Foto dan tanda tangan diunggah ke Supabase Storage, URL-nya disimpan di Supabase Database.
- **Guest Mode:** Memfasilitasi user non-admin agar bisa memantau atau melihat form checklist hasil laporan terkini secara read-only.[cite: 1]
- **Template Logic (Existing):** Terdapat fungsi `getFormTemplate` dan `getEquipmentIdLabel` yang membedakan URL template `.html` serta penamaan ID berdasarkan tipe alat. Fitur ini tetap berjalan untuk keperluan masterlist.[cite: 1]
